

# 🤖 Dream More AI: An AI-powered Student Support Chatbot and Personalized Learning Path Recommender built for Dream More Company.

Dream More AI is an advanced Artificial Intelligence solution developed for **Dream More Company**. It features a smart **Student Support Chatbot** coupled with a **Personalized Learning Path Recommender** to guide students through their educational journeys dynamically.

---

## 💡 Key Features
- **Student Support Chatbot:** An interactive, conversational AI system designed to answer students' academic queries and provide instant updates.
- **Learning Path Recommender:** A machine learning model that analyzes student goals, skills, and backgrounds to generate optimized, tailored learning paths.
- **Personalized Recommendations:** Recommends educational courses, resources, and timelines to bridge knowledge gaps effectively.

---

## 🛠️ Tech Stack Used
- **Language:** Python
- **AI/ML & NLP:** PyTorch / Scikit-learn (or your specific ML library)
- **API Framework:** FastAPI (or Flask/Django if used)
- **Data Handling:** Pandas, NumPy
